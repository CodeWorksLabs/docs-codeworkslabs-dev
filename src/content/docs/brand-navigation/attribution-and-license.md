Brand Navigation is maintained by CodeWorksLabs. It is an independent Discourse theme component, not an official Discourse product. For help or to report a problem, use [Brand Navigation's issue tracker](https://github.com/CodeWorksLabs/brand-navigation/issues).

## License

Brand Navigation is released under `GPL-2.0-or-later`. See the [license](https://github.com/CodeWorksLabs/brand-navigation/blob/main/LICENSE) for its terms.

## Credits

These projects helped inspire Brand Navigation's features and presentation:

- **Discourse Brand Header** — a separate space for your site's branding.
- **Discourse Header Submenus** — structured navigation with dropdown menus.
- **Pavilion Dropdown Header** — dropdowns with descriptive text.
- **Custom Header Links (icons)** — compact icon links in the Discourse header.

You do not need to install these components to use Brand Navigation. If you already use one for your navigation, see [Switch from another header component](../migration-and-rollback/) before replacing it.
