Brand Navigation is maintained by CodeWorksLabs as an independent Discourse theme component; it is not an official Discourse product. For questions and setup help, visit [Brand Navigation Support](https://forum.codeworkslabs.dev/c/brand-navigation/support/7). Report bugs through [GitHub Issues](https://github.com/CodeWorksLabs/brand-navigation/issues).

## License

Brand Navigation is released under `GPL-2.0-or-later`. See the [license](https://github.com/CodeWorksLabs/brand-navigation/blob/main/LICENSE) for its terms.

## Credits

These projects helped inspire Brand Navigation's features and presentation:

- **[Discourse Brand Header](https://github.com/discourse/discourse-brand-header)** — a separate space for your site's branding.
- **[Discourse Header Submenus](https://github.com/discourse/discourse-header-submenus)** — structured navigation with dropdown menus.
- **[Pavilion Dropdown Header](https://github.com/paviliondev/discourse-dropdown-header)** — dropdowns with descriptive text.
- **[Custom Header Links (icons)](https://github.com/discourse/discourse-icon-header-links)** — compact icon links in the Discourse header.

You do not need to install these components to use Brand Navigation. If you already use one for your navigation, see [Switch from another header component](../migration-and-rollback/) before replacing it.

For development history and source references, see the [repository record on GitHub](https://github.com/CodeWorksLabs/brand-navigation/blob/main/docs/PROVENANCE.md).
