Send non-public vulnerability reports to [security@codeworkslabs.dev](mailto:security@codeworkslabs.dev). Do not include credentials, personal data, or private vulnerability details in a public issue.

For the current supported-version and disclosure policy, read the [canonical security policy](/brand-navigation/source/security-policy/).
