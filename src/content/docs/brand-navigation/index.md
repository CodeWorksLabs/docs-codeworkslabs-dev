Brand Navigation gives a Discourse site one coherent place for brand identity, primary links, one-level submenus, and compact header destinations. It is responsive, keyboard-aware, administrator-friendly, and independently maintained by CodeWorksLabs.

:::caution[Release candidate]
The current release is `v1.0.0-rc.1`, published as a prerelease. `v1.0.0` has not been published.
:::

## What it provides

- An optional brand logo, name, destination, and light/dark logo pairing.
- Direct links, submenu-only groups, and linked parents with a separate submenu caret.
- Left and right navigation sections with one intentional child level.
- Per-item audience and desktop/mobile visibility.
- Compact destinations in the Discourse core header.
- Compact-menu, full-bar, and hidden mobile modes.
- Structured settings, validation, and palette-inheriting colors.
- Versioned JSON configuration bundle import and export.
- Keyboard-operable submenus, accessible labels, and safe new-window links.
- Supported embed-context exclusion without DiscussionBridge-specific compatibility code.

Brand Navigation is not a page builder, an authentication replacement, or an official Discourse product.
