## The component does not appear

Confirm the Discourse component is enabled, attached to the active theme, and being viewed on a normal non-embed application page.

## A link or submenu is missing

Check its audience, desktop/mobile visibility, URL, child items, and structured-setting validation state.

## Mobile controls feel crowded

Reduce the number of core-header destinations shown on mobile or use the compact mobile menu.

## A bundle will not import

Confirm it is valid JSON from a supported Brand Navigation bundle version and review the validation message before changing existing settings.

The [expanded troubleshooting reference](/brand-navigation/source/administrator-guide/#troubleshooting) also covers color overrides, missing icons, malformed links, update recovery, and the information to include in a support report.
